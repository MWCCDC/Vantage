Generate New Accounts

Use this to generate random passwords for external accounts

1-67600 accounts (a-z + aa-zz + 1-100)
Available placeholders (all optional):
  • {team} - Team number (e.g., 1, 2, 10)
  • {team:02} - Zero-padded to 2 digits (e.g., 01, 02)
  • {team:03} - Zero-padded to 3 digits (e.g., 001, 002)
  • {letter} - Auto-generated letter (a, b, c...)
  • {number} - Sequential number (1, 2, 3...)
Examples:
team{team}{letter} → team1a, team1b, team2a
team{team}{number} → team11, team12, team21
team{team}{letter}{number} → team1a1, team1a2, team1b1
{letter}{number} → a1, a2, b1, b2
user{number} → user1, user2, user3
All placeholders are optional. Combine {letter} and {number} for complex patterns. {letter} increments before {number} when both are present.
If checked, all accounts for a specific team will share the same password. (Default: Each account gets a unique random password).
Minimum length: 4 characters. Select at least one type.
